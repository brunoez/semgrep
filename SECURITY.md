# Política de Segurança (Security Policy)

## Versões Suportadas

| Versão | Suporte Ativo |
| ------ | ------------- |
| 1.2.x  | :white_check_mark: |
| < 1.2.0 | :x: |

## Como Reportar Vulnerabilidades

Se você identificar uma falha ou potencial vulnerabilidade de segurança:

1. **Por favor, não abra uma issue pública.**
2. Utilize o canal de **Security Advisories** do GitHub ou envie um e-mail para: `brunoez@gmail.com`.
3. Forneça uma descrição detalhada com os passos para reproduzir o problema.
4. Responderemos com a confirmação e plano de correção assim que possível.
